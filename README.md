# Online store project

## Описание:
### Выполнены задания:
- Подключите СУБД PostgreSQL для работы в проекте.
- В приложении каталога создайте модели Product и Category и опишите для них базовые настройки.
- Перенесите отображение моделей в базу данных с помощью инструмента миграций.
- Создайте суперпользователя. Зарегистрируйте модели Product и Category в админке. Настройте отображение для моделей.
- Через инструмент shell заполните список категорий, а также выберите список категорий, применив произвольные рассмотренные фильтры.
- Сформируйте фикстуры для моделей Category и Product.
- Создайте кастомную команду для добавления тестовых продуктов. В команде удалите все существующие данные из базы перед добавлением новых продуктов.
