# Online store project

## Описание:

### Выполнены задания:

- Создайте новый контроллер и шаблон для отображения страницы с подробной информацией о товаре. На этой странице должна
  быть показана вся информация о товаре.
- Добавьте в шаблон главной страницы код для отображения списка товаров с помощью цикла. Чтобы карточки товаров
  выглядели одинаково, обрежьте отображаемое описание до первых 100 символов.
- Из-за увеличения количества шаблонов возникает много повторяющегося кода. Выделите общий (базовый) шаблон, который
  будет включать общие элементы страницы, такие как шапка, подвал и стили. Также создайте подшаблон для главного меню,
  который можно будет включать в другие шаблоны.
